BRY SHARLAND SITE UPDATE

Upload the included files to the SAME paths in your GitHub repository.
Do not upload the README file unless you want to keep it.

This update builds a shared social footer and a live, auto-expiring two-card homepage.
The new News & Events collection is in Pages CMS.

To feature a new artwork, edit the artwork record in Pages CMS and set
'Date added to website' to its publication date (YYYY-MM-DD).
Without a publication date, the artwork will NOT appear as a new feature.
The existing test artwork records have intentionally not been given dates.

For news, create an entry in News & Events, add image, link and publication date.
The default duration is 30 days. Override per record or pin/hide from CMS.
The homepage collapses when neither card is eligible.

Social icons use actual Simple Icons SVG assets from jsDelivr CDN.
If blocked by a browser/network, icons may not render.

Source baseline: brysharland-website-main (2).zip.
Built successfully with python scripts/build.py.
